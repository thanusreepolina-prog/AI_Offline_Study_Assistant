AI Offline Study Assistant – PDF Reader

Project Description

A Python-based desktop application that helps students study PDF notes and ask questions about their content using a locally running AI model.

Features

- Select and read PDF documents
- Extract text from PDF files
- Ask questions about study notes
- Generate answers using a local AI model
- Simple desktop interface built with Tkinter

Technologies Used

- Python
- Tkinter
- pypdf
- Ollama
- Llama 3.2 (3B)

How to Run

1. Install Python and Ollama.
2. Download the Llama 3.2 (3B) model using Ollama.
3. Install the required package: "py -m pip install pypdf"
4. Open the project folder in VS Code.
5. Run: "py pdf_study_assistant.py"

Project Status

The core application has been implemented and tested with sample PDF notes.
